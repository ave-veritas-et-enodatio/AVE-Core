The `clm-eemap1` means-test corpus was to be extended to **muon/tau, neutrino, QCD, cosmological
inflation, substrate-microbiology**.

Measured inside the leaf at HEAD: **neutrino = 0, QCD = 0, inflation = 0, microbiolog = 0,
muon = 1**.

★ **The corpus did grow — 30→31 rows — but along the semiconductor tier** (docket
`2026-07-21-semiconductor-tier-mapping.md`), not these five domains. So this is not neglect; it is
an unstated re-prioritisation. Worth an explicit keep-or-drop rather than carrying five domains that
nobody chose against.
