The queue carries a block explicitly scoped as **"cross-lane and permanent"** and **"now binding on
every future prereg"** — not #796 bookkeeping. All three are freeze-time obligations, *"cheap before
a freeze and unrecoverable after one."*

1. **Every outcome class needs a REACHABLE bin.** #796's frozen bands put the baseline *inside* the
   straddle, so a null-lift vessel could only read UNDETERMINED — *"the whole verdict was loaded onto
   the one measurement that this instrument cannot make. That is the design fault, and it is a
   band-placement fault, not a data fault."* Obligation: at freeze, enumerate HARD / SOFT / NULL /
   UNDETERMINED and show each has a reachable bin.
2. **Gates must be DEMONSTRABLY FIREABLE on known-positives before any verdict arm.** *"A gate that
   has never fired is a checklist, not a gate."* Ship the known-positive fireability demonstration
   *with* the freeze.
3. **Frozen requirements must be checked MUTUALLY SATISFIABLE before freeze.** #796 froze
   `k·r_core ≪ 1` **and** `L ∈ {32,48}` at `φ_sf = 0.489`, which are mutually unsatisfiable, *"and
   nothing in the freeze caught it."* Freeze a precondition-consistency check, **and** freeze what
   the verdict falls back to when a measurement returns non-decisive.

**The problem is location, not content.** The 2026-08-13 freeze put binding, live process discipline
behind a *"Do not append to it"* banner in a document now labelled a historical record. Nothing is
owed on the physics; what is owed is a **decision about where standing process discipline lives** —
a canonical KB leaf, an amendment to the prereg skill (skill changes are hard-gated on Grant), or a
pointer surfaced from the board.
