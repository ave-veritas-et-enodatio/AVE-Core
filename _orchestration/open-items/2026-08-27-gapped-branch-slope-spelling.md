**Two spellings of one branch.**
- `port-register.md`:50, row 4: `ω² = c_κ²k² + m_ω²` with **`c_κ = √2·c`**.
- `cosserat-mass-gap.md`:18, :42, :59 write the same branch as **`ω² = c²k² + m²`**.

Since `v_group = c_κ²k/√(c_κ²k² + m_ω²) → c_κ` as `k → ∞`, the two spellings give
asymptotic packet speeds differing by `√2 = 1.414`, and **the port-register
spelling puts a massive packet's ceiling ABOVE the T2 light characteristic**.

**Complication L1 names:** `cosserat-mass-gap.md`:112 carries a Rule-12 demotion
that explicitly DEMOTES the `c_R = 1` label as *"a continuum idealization the
discrete substrate does not honor"* and ratifies `√2` — **so the leaf's own §1/§2
dispersion relation is written with the slope its own §3.5 demoted.**

**Why this is not cosmetic.** The `two-knob-gravity-repair` result derives a
convergence theorem from the same dispersion: because the gap drops out as
`ω ≫ Ω`, a fast massive packet **must** asymptote to *its own channel's* massless
ray, with `α·b/(GM/c²) → 2a₁`. **Which channel that is, and therefore which
massless ray it converges to, is exactly what this spelling decides.** It also
decides whether matter is sub- or super-luminal at high `k`, which is a
foundational question, not a notation question.
