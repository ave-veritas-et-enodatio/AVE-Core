carries no discriminating content.

lemma, #955 §7's STUCK-POINT) is **not a fork to adjudicate**: the lapse is the **in-regime law**

Stage-4 peel target is not an embarrassment awaiting rescue; it is **an edge prediction**, which is
the class of object the program is now organized around.
