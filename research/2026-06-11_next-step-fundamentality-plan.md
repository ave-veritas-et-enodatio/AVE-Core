## §3 — The combination analysis (parallel-pressure-test premise-coupling check)

The rule (`feedback_parallel_pressure_test` / `ave-discriminator-before-synthesis`): **never run two
builds that share an unadjudicated premise.** Resource-coupling (two expensive builds competing for the
same machine/attention) is a scheduling concern, not a premise concern — it is flagged but does not
forbid. Premise-coupling forbids.

**The premise-coupling matrix (which pairs SHARE an unadjudicated premise):**

| Pair | Shared premise | Adjudicated? | Parallel-safe? |
|---|---|---|---|
| **1 ↔ 6** | the substrate net is srs (z=3) | **NO** — frozen pending Grant (audit §3.1) | **FORBIDDEN** — 6 must wait for 1 |
| 4 ↔ 5 | transport DOF exists | partial — 4 builds it; 5 consumes it | sequential (hard gate), not parallel |
| 2 ↔ 3 ↔ 4 | none shared | n/a | **parallel-safe on premise** (resource-coupled only) |
| 0 ↔ 0b | none shared (different framing calls) | both Grant-gated, independently | **parallel-safe** (doc lane) |
| 0/0b ↔ any sim | none (different lane) | n/a | **parallel-safe** (doc/prereg vs integrator) |
| 2 ↔ 5 | σ-shell is the release surface | feeds, not premise-shared | parallel-safe (2 informs 5, no premise lock) |

**The one hard FORBIDDEN pair is 1 ↔ 6.** v9 Phase-1 (6) is a build whose entire premise — that the
substrate is srs — is exactly the question candidate 1 adjudicates. Building 6 before 1 is decided is the
textbook parallel-pressure-test violation (a build standing on an unadjudicated premise); it is also what
`[branch #195]`'s own freeze flag already forbids. **Keep them serialized: 1, then (if framing A or a
green-lit B) 6.**

**Premise-safe parallel sets** (may run concurrently without premise-coupling):

- **{0, 0b}** — the two pre-sim doc/prereg/bench candidates. Different framing calls, no shared premise.
  Run both in the pre-sim layer.
- **{2, 3, 4}** — the three premise-independent engine builds. No shared unadjudicated premise; **only
  resource-coupled** (all three are medium-to-expensive integrator work). Sequence by fundamentality

- **{0 or 0b} ‖ {any one sim}** — the doc lane and the integrator lane never share a premise; the pre-sim
