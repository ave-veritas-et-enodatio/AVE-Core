## §2 — The surf-retraction (walk-level, orchestrator)

The walk first considered Reading A under a **transport** reading — the caged mass "surfing" the passing carrier — and **retracted it**. Reading A does **not** require transport. It requires only that the cage **oscillate with the local material velocity of a passing carrier** (sway, not carriage). A cage need not travel with the wave to load its inertia; it needs only to be swayed by the same node displacements the wave is made of. This retraction is load-bearing for §4: it removes the "you need speed to surf" objection before it is raised, by denying that surfing (transport) was ever the mechanism.

## §4 — The relative-offset argument (walk-level, orchestrator)

**Everything in this section is walk-level unless a cite is attached.** The canon leaf adjudicates.

**(a) The envelope has no cosmic rest-frame pin.** The **lattice / crystal frame exists** — cosmologically it is the CMB-isotropy frame, the frame in which `Ω_freeze` is defined (`cosmic-axes-and-frames-glossary.md` `[canon]`: "K4 lattice rest frame `=` CMB rest frame"; `preferred-frame-and-emergent-lorentz.md` `[canon]`). But a **boosted breather** is an **equally valid lossless solution** below the band edge: there is no aether drag, and a lossless soliton translating uniformly through the cold lattice radiates nothing. So the crystal has a frame, but the **excitation is not pinned to it** — the soliton's rest frame is **its state of motion, set by its history**, not the crystal's frame. (Grant's "the CMB?" is answered: the CMB frame is the *crystal's* frame, not the *envelope's* — the envelope has no cosmic pin.)

**(b) The relative-offset principle (the new canon object).** In a **phase-only substrate**, position is defined **only on the node graph**; there is **no spatial frame beneath it**. A localized excitation is a **pattern on nodes**. Where its host nodes displace, the pattern's energy goes. For a pattern to **hold station against the material displacement of its nodes** it would have to **hop node-to-node in exact compensation** (anti-advection) — and that requires a **spatial anchor beneath the graph**, which is exactly what phase-only forbids. Therefore a trapped pattern **cannot hold station against material displacement**; it participates in it.

**(c) Corollary A — discrete pinning delivers material tracking, not station-keeping.** Discrete (Peierls-Nabarro-class) pinning pins to **node INDICES**, and node indices **displace with the carrier**. So pinning delivers **FULL material tracking**, not station-keeping — there is **no pinned escape from advection**. (Pinning is often read as "the defect is stuck in place"; on a phase-only graph "in place" means "at these node indices," and those indices move with the medium.)

**(d) Corollary B — this is the mechanism-side of no-aether-drag.** The same fact, seen from the **excitation's** side, is the mechanism-level statement of **why there is no aether-drag observable** (emergent-relativity self-cancellation): the excitation and the rulers/clocks made of the same medium share the offset, so a uniform relative offset is unobservable. (Corpus side: `preferred-frame-and-emergent-lorentz.md` — the frame exists but is optically undetectable at observable wavelengths; the AC/DC carve `clm-acdc07` — all measurement is AC, a uniform DC offset self-cancels.)

**(e) Corollary C — the Fork-ρ direction.** Because trapped-energy patterns **participate in any carrier's oscillatory material motion**, the trapped mass **loads** the effective inertia `ρ_eff` — so the **direction** of Fork ρ is **Reading A (toward MATCHED)**.
