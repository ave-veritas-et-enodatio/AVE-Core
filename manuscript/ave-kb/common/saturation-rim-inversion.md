## The inversion statement (claim 1 — Grant-ratified MAPPING, consistency-class reading)

The Axiom-4 kernel

$$

is a **circle constraint** ([`universal-saturation-kernel-catalog.md:11,20`](universal-saturation-kernel-catalog.md); the same unit-circle structure the catalog notes for the SiLU-saturation instance, :298). Read a single mode's reactive state as a point in the **(amplitude `A`, phase `θ`) plane** — the **disk** of radius `A_yield`, with `A` the conserved reactive-amplitude **envelope** (the cycle time-average of the `(V_inc, Φ_link)`-type tank, [`substrate-perspective-electron.md:62`](../vol2/particle-physics/ch01-topological-matter/substrate-perspective-electron.md)), not an instantaneous snapshot. Then:

> **Cold lattice = amplitude-dynamic, phase-trivial; saturated core = amplitude-frozen, phase-topological — the dynamics and topology swap roles; the core's state space is the BOUNDARY of the baseline's state space.**
>
> A **cold node** lives in the **disk interior**: both amplitude and phase are dynamical, and because the mode's own amplitude can wander toward `A → 0`, any winding it carries can **unwind** through the center — the interior confers no protection. A **saturated core** is pinned **ON the rim** `A = A_yield`, where `S → 0` and the local clock **freezes** (`c_eff = c·√S → 0`, "stable because it is static", [`genesis-chord-falsification-ledger.md:145`](genesis-chord-falsification-ledger.md)): amplitude is frozen, only **phase** remains free, and phase on the rim circle is classified by **winding numbers** (`π₁(S¹) = ℤ`).
>
> **The rim is where the winding is MAXIMALLY PROTECTED — not where integers first exist.** Winding integers live on the whole **punctured disk** (any `A ≠ 0` supports `π₁ = ℤ`); the rim's amplitude freeze-out **removes the unwinding channel** (`A → 0`), so a winding pinned there cannot decay. Existence of the integer is a property of any `A ≠ 0` circle; the rim confers **maximal protection**, not existence. The corpus carries the counterexample in-house: the electron's **A1 mass port operates sub-saturated at `A = √α ≈ 0.085`, `S ≈ 0.996`** — a **disk-interior** locus at the ratified Q-point ([`resonant-lc-solitons.md:138`](../vol4/circuit-theory/ch1-vacuum-circuit-analysis/resonant-lc-solitons.md)), **not** on the rim.
>
> **The charge↔saturation coupling is a locus-of-PROTECTION consistency reading, NOT a quantization mechanism (consistency-class; the nearest dynamical tests read NEGATIVE).** Charge is the **STATIC imposed Link** — `charge = Link(∂Ω, F)` STANDS per the Grant-ratified **#416 two-natured ruling** ([`research/2026-06-24_engine-reroute-epic-summary.md:5,20,24`](../../../research/2026-06-24_engine-reroute-epic-summary.md): the electron is two-natured — a DYNAMICAL energy-bound A1 mass + a STATIC topological `(2,3)`-Clifford-winding charge) — **not** a rim integer that dynamically "closes." The corpus's nearest tests of a *dynamical* charge-winding read **NEGATIVE at both loci**: the real-space coupled eigensolve (**#415**) bled the `(2,3)` off the bound mode, and the phase-space coupling orbit at the yield front (**#59**) read the **carrier ratio** `(−5,−5) = (1,1)`-class, **not** `(2,3)`. Per [`the-abandoned-interior.md:111`](the-abandoned-interior.md): *"the `(2,3)` winding does NOT dynamically 'close' at any `V` — it is a **static Clifford-torus / Link texture**."* So the rim statement is the **locus of protection** — an imposed static Link is maximally protected where saturation freezes the amplitude — a **consistency reading over the static-Link canon**, NOT a mechanism that quantizes charge by reaching the rim.

**This is a reading, not a derivation.** Every piece is already canonical — the circle shape (Axiom 4), the frozen clock at yield (the genesis ledger), and the phase-space `(2,3)` winding ([`the-abandoned-interior.md:46`](the-abandoned-interior.md); [`electron-identification.md`](../vol2/particle-physics/ch01-topological-matter/electron-identification.md) §1 property 2, verbatim: *"The `(2,3)` 'trefoil' is the phase-space winding pattern, NOT a real-space trefoil knot."*). The leaf assembles them into one organizing identity. It is a **near-theorem** of those objects; it originates no new numerical commitment.

**Disk vs Clifford torus (precise geometric content — flag, not overclaim).** The corpus's `(2,3)` winding lives on the **Clifford torus** = the product of the bond-pair's **two** phase circles `(V_inc, V_ref)` ([`substrate-perspective-electron.md:243,247`](../vol2/particle-physics/ch01-topological-matter/substrate-perspective-electron.md); [`mathematical-topology-of-mass.md:30`](../vol2/particle-physics/ch01-topological-matter/mathematical-topology-of-mass.md)). The disk→rim reduction above is the **single-mode** statement; the rim-circle of each of the two bond-pair modes is one **factor** of that torus. The inversion therefore says *why* the saturated phase space is **toroidal** — each factor is a rim-circle (frozen amplitude, free phase) — and *why* the winding is an integer pair `(2,3)` (a `π₁` class of the torus `= ℤ×ℤ`). At the swing-railed core the impedance ordering of the channels **flips** versus cold vacuum — the core is the impedance **DUAL** of the medium. This is a **re-reading of an already-Grant-ratified split** (INVARIANT-S2, Grant-ratified 2026-06-15), **not** a new result:

- **EM / transverse channel OPENS.** The **transverse-T2 permittivity** `ε_eff = ε_0·S → 0` (the swing-ε kernel; `ε_eff = ε_base·√(1−(V/V_yield)²)`, `src/ave/core/fdtd_3d_jax.py:109-113`; [`universal-saturation-kernel-catalog.md:170`](universal-saturation-kernel-catalog.md)), so `Z_wave = √(μ/ε) → ∞` — the **open/rupture read**. Orthogonal reactances, both `|Γ|=1`, differing only in boundary phase."*

So the core reflects **both** channels perfectly (`|Γ|=1`) but with **opposite boundary phase**: `Γ = −1` (short) in the A1/bulk channel, `Γ = +1` (open) in the T2/transverse channel. That opposite-phase pair **is** the "impedance dual / ordering flips" statement — and it is the INVARIANT-S2 sector split, already ratified.
